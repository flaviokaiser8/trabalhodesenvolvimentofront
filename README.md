# Projeto React - Context API

Este projeto foi desenvolvido utilizando React e Context API (`useContext`) para gerenciamento global de estados.

## Tema escolhido
Tema Claro/Escuro

## Funcionalidades
- Alternância entre tema claro e escuro
- Gerenciamento global de estado com Context API
- Componentes consumindo contexto
- Interface simples e funcional

## Tecnologias utilizadas
- React
- Vite
- CSS

## Como executar o projeto

```bash
npm install
npm run dev
